# Vortex releases

Windows installers and signed application updates for Vortex are published in
[Releases](https://github.com/wycux/vortex-release/releases).

Download the latest stable `Vortex-v<version>-setup.exe`, close Vortex through
**Quit** in the tray, and run the installer. Installation is per user; FFmpeg and
FFprobe are included.

After installing Vortex 2.6.0 or later, updates are available in the application:
**Settings → General → Vortex → Check for updates → Update → Restart Vortex**.
Vortex also checks once after startup. Download and restart require your action.

The `.sig` and `latest.json` files are used by Vortex to verify and deliver updates.
You do not need to install these files manually.

This repository hosts release assets. Application source is maintained separately.
